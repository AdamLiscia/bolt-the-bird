- 2026-11-18 — P2, first evaluation (1,500 deck pairs, sides swapped, vs the rules-based player): 0.7%. Two bugs, both fixed test-first: (1) the cast model splits its confidence across identical cards (three Plains at 0.3–0.5 each), so a per-card threshold skipped land drops — scores are now pooled per card; (2) plans were keyed on id(game), and Python reuses ids, so from the second game in each worker the player followed a dead game's plan and passed every turn — plans now reset per game. Fixed: **23.5% ± 0.8%** (control rules vs rules 48.6%). Diagnosis: it plays lands like the rules-based player (7.3 vs 7.7 a game) but casts 6.4 spells against 10.5 and attacks 5.6 times against 8.7. People hold instants and tricks for the opponent's turn; this player never acts at instant speed, so held cards rot. Options: casting what's left in the second main phase 31.7%, attacking at a 0.35 threshold 26.9%, both **39.4% ± 0.9%**. Tuned against the same opponent, so read that as an upper bound. P2's goal (beat the rules-based player) isn't met: turn-level imitation copies people's restraint without their instant-speed follow-through. That gap is P3's job.
- 2026-11-18 — P3 designed (docs/play/P3_DESIGN.md): one network scores every legal move (state tokens for every visible object, action tokens that point at the objects they name, policy and value heads); distillation from the smart player first, then PPO self-play against a league (itself, past checkpoints, the rules-based and smart players) with a decaying KL leash, reward only for winning. Measured: ~208 decisions with a real choice per game (priority 165, attackers 25, targets 7, blockers 6); rules-based self-play ~290 games/s in one Python process; an observation ~14 µs.
